# Steam Free Games باستخدام n8n

متابعة عروض **التملك الدائم المجانية** للألعاب والإضافات على Steam، ومحاولة إضافتها لحسابك لو مستوفي الشروط، وإرسال صورة اللعبة واسمها وسعرها السابق وحالة الإضافة على تليجرام.

الخدمة بتشتغل جنب n8n في Docker، ومش محتاجة SSH Private Key أو تعديل الـrunner أو تثبيت مكتبات جوه نود Code.

> **نسخة تجريبية v0.1.0:** الاختبارات البرمجية نجحت، لكن إضافة لعبة فعلية بنجاح من النسخة المحمولة لسه مش مؤكدة. راجع [حالة التحقق](VALIDATION.md). المشروع مستقل ومش تابع لـValve أو Steam أو n8n.

## هتضبط إيه؟

| البيانات | مكانها |
| --- | --- |
| دخول Steam وSteam Guard | ترمينال سيرفرك مرة واحدة؛ الباسورد مش بيتحفظ |
| مفتاح الخدمة اللي هيتولد | Header Auth داخل n8n، بهيدر `X-API-Key` |
| توكن بوت تليجرام | Telegram credential داخل n8n |
| Chat ID | نودات تليجرام في الـworkflows |

بعد تجهيز Docker والربط، مفيش تعديل كود عشان تحط بياناتك. لكن مفيش Steam credential رسمي يعمل العملية دي من غير تسجيل دخول أول مرة؛ Steam Web API key لوحده مش كفاية، وممكن Steam يطلب إعادة تسجيل الدخول مستقبلًا.

## المشروع بيعمل إيه؟

- يبحث عن عروض الألعاب والـDLC بخصم 100% في متجر Steam.
- يراجع إن العرض للتملك الدائم والترخيص المجاني واضح.
- لو الـDLC محتاج أساسية مش عندك، يفحص لو مجانية؛ يحاول يضيفها الأول ويتأكد منها قبل الـDLC.
- ما يشتريش ألعاب مدفوعة، وما يحسبش `Play For Free` المؤقت تملك دائم.
- ما يقولش «اتضافت» إلا بعد تأكيد ملكية التطبيق أو الباكدج.
- يبعت صورة ونص، أو نص فقط لو مفيش صورة من المصدر.
- يشتغل كل ساعة، ويمنع تكرار نفس الحالة والسبب لمدة سبعة أيام في التشغيل المجدول الناجح.
- يوفّر workflow منفصل لتنبيهات الأعطال العامة.

## ابدأ

```bash
git clone https://github.com/Ebnhussein/n8n-steam-free-games.git
cd n8n-steam-free-games
docker compose build
docker compose run --rm steam-helper node src/cli.cjs init
docker compose run --rm steam-helper node src/cli.cjs login
docker compose up -d
```

بعد الأوامر، لازم تربط شبكة n8n وتستورد الـworkflow وتعمل الكردنشلز. [الشرح الكامل بالترتيب](SETUP.ar.md) فيه كل خانة هتحط فيها إيه، وعمل البوت ومعرفة Chat ID والتجربة والتفعيل.
