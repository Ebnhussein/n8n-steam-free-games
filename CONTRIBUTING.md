# Contributing

Run `npm ci` and `npm test` on Node 22 or newer. Add anonymized fixtures/tests for parsing and claiming changes. Keep live-account checks opt-in; CI must never use Steam or Telegram secrets.

Useful contributions: regional Store fixtures, age-gate detection, license error classification, Docker architecture validation, n8n import validation, and successful claim integration reports. Distinguish observed ownership from an unconfirmed request. Do not submit account tokens, personal execution URLs, or exported credential IDs.
